# Контекст проекта

DataBasesAndCachePatterns — **чисто ознакомительный проект**.

Цель: личное сравнение конкурентных паттернов Go (fan-out по шардам, гонка до
первого ответа, single-flight) между их самописной реализацией на примитивах и
готовыми библиотеками `golang.org/x/sync`.

## Правила работы

- Это не production-код. Приоритет — читаемость и наглядность сравнения.
- Не добавлять тесты, линтеры, CI и прод-обвязку без прямой просьбы.
- Не рефакторить «на продакшн»: если пример написан на каналах — пусть остаётся
  на каналах, даже если есть вариант на мьютексе. Оба варианта должны лежать рядом.
- Комментарии в коде — часть учебного смысла, не вычищать их.
- Новые паттерны класть в `Patterns/<pattern-name>/`, пакет с суффиксом `pattern`.
- `go vet ./...` должен проходить; он используется как единственная проверка.
